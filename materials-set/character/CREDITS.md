# Original Character PBR

An original one-eyed service robot built from Blender primitives by the project build script. No third-party meshes or textures are imported.

Modeling: rounded rectangular helmet, single optical lens, antenna, chest vents, backpack battery, jointed arms, two-finger grippers, segmented legs and boots.
PBR materials: blue metallic shell, brushed steel joints, copper trims, matte rubber, dark glass and an emissive cyan eye. All use Principled BSDF and export to glTF metallic-roughness materials.

Source: original-robot.blend. Build script: build-robot.py (run in Blender background mode). Export: robot-pbr.glb. Studio-rendered image: original-robot-preview.png.
